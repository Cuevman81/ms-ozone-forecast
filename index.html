Data Pipeline

Data is synced via the R pipeline (GitHub Actions or manual Rscript run). The export script generates the JSON files this dashboard reads.


To refresh data:

  1. Run Ozone_Master_Sync.R (updates data + models + forecasts)
  2. Run web-dashboard/export_json.R (exports JSON for this dashboard)
  3. Push or deploy

Model Details

This application uses a Random Forest regression model to forecast the following day's peak 8-hour ozone concentration based on persistence, forecasted meteorology, and NOAA air quality model outputs.
